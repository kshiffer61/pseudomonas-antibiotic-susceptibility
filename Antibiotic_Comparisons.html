Pair summaries

For each ordered pair: N = all samples, M = first-drug NS, Y = first-drug NS and second-drug S. Conditional rescue is Y/M, added coverage is Y/N, and total coverage is (N-M+Y)/N.

pair_summary <- function(data, first, second) {
  N <- nrow(data)
  M <- sum(data[[first]] == 1)
  Y <- sum(data[[first]] == 1 & data[[second]] == 0)
  data.frame(First = first, Second = second, N = N, Missed = M, Rescued = Y,
             First_percent = 100 * (N - M) / N,
             Conditional_percent = if (M > 0) 100 * Y / M else NA_real_,
             Added_points = 100 * Y / N,
             Combined_percent = 100 * (N - M + Y) / N)
}
pairs <- expand.grid(First = top_five, Second = top_five, stringsAsFactors = FALSE)
pairs <- pairs[pairs$First != pairs$Second, ]
comparison <- bind_rows(lapply(seq_len(nrow(pairs)), function(i) {
  pair_summary(samples, pairs$First[i], pairs$Second[i])
}))

Using each pair’s available samples retains more observations; the observed ordering of the three additions is unchanged for either starting drug. The full set of 20 directional comparisons is exported to CSV.

Limitations

Complete testing may select a different population, and patient labels cannot be linked across years. Sample rankings and 100% observed coverage do not establish population rankings or guaranteed coverage in future samples.
