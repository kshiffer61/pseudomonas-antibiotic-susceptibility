Antibiotic susceptibility in respiratory Pseudomonas aeruginosa

Basel laboratory data, 2015-2018. This analysis estimates ciprofloxacin susceptibility conditional on piperacillin-tazobactam results and the added coverage of the pair. S = susceptible; NS = nonsusceptible.

Data preparation

The shared script reads pinned public files and collapses repeated measurements to one result per laboratory order. Mixed or conflicting clear results are unclassified; see scripts/prepare_data.R for the cleaning code.

Added coverage

P(A and B) = P(A) P(B given A). Added coverage uses all N samples as its denominator, while conditional rescue uses the M samples missed by pip-tazo.

r_hat <- M / N
added <- Y / N
first_coverage <- mean(!A)
combined_coverage <- mean(!A | B)

coverage <- data.frame(
  Quantity = c("Pip-tazo S", "Cipro S given pip-tazo NS", "Added coverage", "Combined coverage"),
  Numerator = c(sum(!A), Y, Y, sum(!A | B)),
  Denominator = c(N, M, N, N),
  Percent = 100 * c(first_coverage, q_hat, added, combined_coverage))

Maximum likelihood

Model M as Binomial(N, r) and Y given M as Binomial(M, q); the MLEs are r = M/N and q = Y/M. This assumes approximately independent patient-year observations with common probabilities across the period.

r_values <- seq(0.05, 0.30, length.out = 150)
q_values <- seq(0.25, 0.90, length.out = 150)
log_likelihood <- outer(dbinom(M, N, r_values, log = TRUE),
                        dbinom(Y, M, q_values, log = TRUE), "+")
maximum <- dbinom(M, N, r_hat, log = TRUE) + dbinom(Y, M, q_hat, log = TRUE)
relative_likelihood <- exp(log_likelihood - maximum)

par(mar = c(5, 5, 3, 1))
image(100 * r_values, 100 * q_values, relative_likelihood,
      col = colorRampPalette(c("white", "steelblue"))(50),
      xlab = "r: pip-tazo NS (%)", ylab = "q: cipro S given pip-tazo NS (%)",
      main = "Relative likelihood for r and q")
points(100 * r_hat, 100 * q_hat, pch = 4, cex = 1.3)
legend("topright", sprintf("MLE: r = %.1f%%, q = %.1f%%", 100*r_hat, 100*q_hat),
       bty = "n", cex = 0.85)

Darker cells have higher likelihood relative to the maximum; the cross marks the MLE. The colors describe fit to the observed counts, not probabilities that the parameter values are true.

Scope

Coverage describes historical laboratory susceptibility, not clinical recovery or treatment effects. Missing testing, selection of eligible samples, and unlinked patient labels across years limit generalization.
